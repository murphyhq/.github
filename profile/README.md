**Anything that can go wrong will go wrong, and Murphy makes sure someone hears about it.**

### Principles

- **Focused**: incident response first, next to the monitoring you already run.
- **Free means free**: the server costs nothing; only hosted services carry a price.
- **Self-hostable**: your alerts, your data, your infrastructure.
